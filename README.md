# Kafka Tools
Sistem Informasi Inventaris Alat berbasis web yang dirancang untuk mengelola peminjaman dan pengembalian inventaris sekolah secara efisien.

Fitur Utama:

Backend: Mengelola database peminjaman, data user, dan log aktivitas.

UI/Frontend: Antarmuka yang ramah pengguna untuk Admin, Petugas, dan Peminjam.

Fitur Spesial: Log aktivitas sistem untuk memantau setiap transaksi yang terjadi.
